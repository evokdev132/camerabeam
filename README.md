# Camerabeam

Веб-страница с AR-вейпоинтом: ставите метку на карте, включаете камеру — на месте метки поднимается столб света.

- Положение — GPS, направление — компас и гироскоп телефона (DeviceOrientation).
- Угол обзора камеры и поправка компаса настраиваются; кнопка «Смотрю на точку» калибрует компас по известному ориентиру.
- Работает только по HTTPS (камера, геопозиция и датчики иначе недоступны). Проще всего — GitHub Pages: Settings → Pages → Branch `main`, папка `/`.

Один файл `index.html`, без сборки. Карта — Leaflet + OpenStreetMap.
